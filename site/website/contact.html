Questions fréquentes

Le launcher est-il gratuit ?

Oui, totalement : pas d'abonnement, pas de pub, pas de compte « launcher » à créer. Tu te connectes avec ton vrai compte Microsoft, comme sur le launcher officiel.

Est-ce que ça marche avec TLauncher / un compte cracké ?

Non. Team Launcher exige une licence Minecraft : Java Edition officielle. C'est ce qui permet la connexion Microsoft sécurisée et les skins réels.

Faut-il installer Java soi-même ?

Non. Le bon Java est téléchargé automatiquement selon la version du jeu, et mis en cache pour les lancements suivants.

Mes amis peuvent-ils rejoindre mon serveur sans être sur mon Wi-Fi ?

Oui : l'onglet Réglages du serveur → « Ouvrir sur Internet » crée une adresse publique playit.gg, sans ouvrir les ports de ta box.

Où sont stockées mes instances et mes serveurs ?

Dans %LocalAppData%\TeamLauncher. Rien n'est envoyé ailleurs : aucune donnée n'est collectée par le launcher.

Comment désinstaller proprement ?

Désinstalle le launcher depuis Windows, puis supprime le dossier %LocalAppData%\TeamLauncher si tu veux aussi effacer instances, serveurs et sauvegardes.

🔧

Avant de écrire

Pour un crash de Minecraft, regarde déjà la fenêtre d'analyse qui s'affiche après la fermeture du jeu : elle explique souvent la cause (RAM insuffisante, mod incompatible, mauvaise version de Java…) et la solution.
